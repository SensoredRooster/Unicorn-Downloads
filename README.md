# Unicorn desktop downloads

[Download the latest Windows installer](https://github.com/SensoredRooster/Unicorn-Downloads/releases/latest)

Close Unicorn and install over your existing version. Version 0.3.0-preview.7 is the first build configured with this public update feed. Older builds need this one manual installation; their update button cannot discover this feed.

After that, use **Check for updates** in Unicorn. The app asks before downloading and before restarting to install. This repository contains installers, blockmaps and update metadata only. The application source stays private.

Model connections are separate. Never post owner or tester connection JSONs here; they contain private inference keys. Local hardware fit tags are memory estimates, not performance guarantees.
